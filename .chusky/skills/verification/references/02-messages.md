# Verify messages and email

## Check before send

- Recipient identity and thread correctness
- Facts match sources (no invented amounts, dates, names)
- Ask / CTA is clear
- Tone matches owner voice when representing them
- Attachments only if verified paths exist

## After send

- Require tool confirmation (message id / success payload)
- Never say sent on draft-only

## Draft vs send

If policy requires approval, stop at draft and say so explicitly.
