## Core loop

1. Create
2. Check against explicit criteria
3. Fix failures
4. Check again
5. Only then claim done

## Non-negotiables

- Tool success ≠ user outcome
- "Looks right" is not verification for files, UI, or docs — inspect the artifact
- Never invent paths, previews, or send confirmations
- If the same check fails twice, stop and report the blocker
- Do not silently retry side-effecting actions that may have already succeeded

## Done means

- Stated objective met
- Evidence exists
- Residual risks stated
