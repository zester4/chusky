# Toolkits for support desk

| Need | Toolkit family |
|------|----------------|
| Tickets | `ZENDESK_`, `FRESHDESK_`, `GORGIAS_`, `PLAIN_`, `ZOHO DESK_` |
| Messaging support | `INTERCOM_`, `FRONT_` |
| Customer context | CRM map (`HUBSPOT_`, …) |
| Status / incidents | `STATUSPAGE_` if any, else `GITHUB_`/`LINEAR_` for eng bugs |
| Knowledge | `NOTION_`, help-center docs via fetch |

Triage in the helpdesk system of record when connected — do not only reply in chat.
