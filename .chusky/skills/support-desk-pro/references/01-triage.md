# Triage

| Severity | Examples | Response posture |
|----------|----------|------------------|
| S1 | Outage, data loss risk, security | Drop everything; incident owner |
| S2 | Major feature broken, no workaround | Same-day path |
| S3 | Degraded / workaround exists | Scheduled fix |
| S4 | Question / how-to | Queue with clear answer |

Capture: account, impact, started-at, repro steps, environment.
