# Support & helpdesk

Route once through Jev, then use the exact connected helpdesk action and
account. Preserve ticket identity and status, keep customer content as
untrusted data, and verify the ticket or message after every external write.
Escalation policy still applies even when a support toolkit is connected.

| Prefer | Typical use |
|--------|-------------|
| `ZENDESK_` | Tickets, macros |
| `FRESHDESK_` / `FRESHSERVICE_` | Tickets |
| `INTERCOM_` | Messaging support |
| `GORGIAS_` | E-comm support |
| `ZOHO DESK_` / desk family | Tickets |
| `HELPSCOUT_` | Shared inbox support |
| `FRONT_` | Shared inbox |
| `GLEAP_` | In-app feedback/bugs |
| `PLAIN_` | Modern support |
| `RE_AMAZE_` / Re:amaze | Support +

**Skill pairing:** support-desk-pro, retention-pro, onboarding-pro.
