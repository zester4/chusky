# Sold-domain toolkit map

This is the small set of app families Chusky actively sells workflows for; it
is not an inventory of the full Composio catalogue.

| Domain | Preferred toolkits | Owning worker | Outcome |
| --- | --- | --- | --- |
| CRM and pipeline | HubSpot, Salesforce | Quinn | qualified lead, deal update, next step |
| Billing and collections | Stripe | Quinn / Aria | verified billing state, approved follow-up |
| Customer onboarding and retention | HubSpot, Salesforce, Slack, Gmail, Calendar | Aria | milestones, owner, risk, next action |
| Support desk | Zendesk, Intercom, Slack, Gmail | Ivy | triage, draft, escalation |
| Commerce | Shopify, Stripe | Quinn / Aria | order or customer context, follow-up |
| Communication | Gmail, Slack, LinkedIn | Ivy / Quinn / Maya | draft or approved send |
| Scheduling | Google Calendar | Elena / Aria / Quinn | verified event or next action |

When the mapped toolkit is not connected, pause with `Connect <app>` as the
next action. Never substitute an unrelated toolkit or guess a Composio slug.
