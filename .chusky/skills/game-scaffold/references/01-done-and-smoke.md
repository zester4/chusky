# Done bar and smoke test

## Playable checklist

- [ ] Page/route loads; no blocking console errors
- [ ] Loop runs (entity positions or timer change over time)
- [ ] At least one input path works (keyboard or pointer)
- [ ] HUD shows score, time, or state
- [ ] Failure or win is reachable (or endless mode is explicit)
- [ ] Restart or “play again” works if the run can end

## Smoke procedure (Daytona or local)

1. Serve or open the entry file / route
2. Focus the game surface; press primary keys / click
3. Confirm motion or state change within 2 seconds
4. Force fail or win once if applicable
5. Restart once

If any step fails: fix before adding art, audio packs, or extra genres.

## Evidence

When reporting to the owner: say what was run and what was observed (e.g. “arrow keys move player; score increments on coin”). Do not say “should work.”
