# Genre minimums (scaffold only)

Ship the smallest loop that *is* that genre. Polish later via building-games.

| Genre | Minimum |
|-------|---------|
| **Snake** | Grid, growing body, food, wall/self fail, score |
| **Tetris-like** | Falling piece, rotate, clear line, score, top-out |
| **Platformer** | Run, jump, gravity, one solid platform, hazard or goal |
| **Top-down arena** | Move, one enemy or projectile, hit, score/lives |
| **Endless runner** | Auto-scroll, jump/slide, obstacle, score by distance |
| **Pong-like** | Paddle(s), ball bounce, score |
| **Clicker / idle** | Click adds resource; at least one upgrade |
| **Simple shooter** | Move or aim, fire, enemy spawn, hit, score |
| **3D arena (later)** | Ground, player move, camera; then enemies — after 2D discipline |

If the user names a genre not listed: map to the closest row and say so in one line.
