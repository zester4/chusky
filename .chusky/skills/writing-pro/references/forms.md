# Writing Forms

## External email
- First line states purpose
- One ask max when possible
- Explicit owner and timing if action is needed

## PRD / product doc
- Problem, users, goals, requirements, non-goals, milestones
- Acceptance criteria for each major requirement

## Status update
- Outcome progress first
- Blockers second
- Asks third

## Announcement / release
- What changed
- Who it affects
- What to do
