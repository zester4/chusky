# Retention communications

## Check-in (yellow)

Purpose + observation + question + offered help + easy reply path.

## Risk (red)

Direct, calm, ownership: what we see, impact, plan, ask for 15 minutes.

## Renewal

Value first, logistics second, ask third.

## Rules

- One primary CTA per message
- Match owner voice
- No fake urgency
- After calls: recap in writing same day
