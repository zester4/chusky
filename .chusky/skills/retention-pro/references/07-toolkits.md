# Toolkits for retention

Load `composio-routing` if unsure. Prefer:

| Need | Toolkit family |
|------|----------------|
| Account / deal context | `HUBSPOT_`, `SALESFORCE_`, `PIPEDRIVE_` |
| Tickets / friction | Support map (`ZENDESK_`, `INTERCOM_`, …) |
| Usage or product signals | Native analytics or connected BI if any |
| Renewal paperwork | `GOOGLEDRIVE_`, `NOTION_`, e-sign if connected |
| Payment risk | `STRIPE_` + billing-ops-pro |
| Outreach | `GMAIL_`, `SLACK_` |

Handle routine pulls; digest commercial concessions.
