# Churn risk playbooks

## Common patterns

| Risk | First moves |
|------|-------------|
| Low adoption | Re-run first-win path; training; simplify setup |
| Product friction | Reproduce issue; escalate product/support with evidence |
| Payment failure | Billing ops path; polite recovery sequence |
| Champion exit | Map new stakeholders within 48h |
| Competitor eval | Value review; roadmap honesty; executive align if needed |
| No engagement | Multi-channel nudge; then manager-level outreach |

## Operating rules

- Create an `open_loop` per red account with dueAt
- Time-box: if no response in N days, escalate channel/seniority
- Separate **product problem** vs **fit problem** vs **commercial problem**
- Never bad-mouth competitors; win on clarity and outcomes

## Exit criteria for risk loop

Risk reduced with evidence (usage back, payment cleared, new champion engaged)
or owner decides controlled offboard.
