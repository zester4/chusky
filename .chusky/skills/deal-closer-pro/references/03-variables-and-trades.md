# Variables and trades

Price is one lever. Professionals negotiate a **package**.

## Expand the pie (variables)

| Dimension | Examples |
|-----------|----------|
| **Price** | List, ramp, multi-year rate, prepaid discount |
| **Scope** | Seats, modules, environments, custom work |
| **Time** | Start date, go-live, phased delivery |
| **Term** | 12 vs 24/36 months, opt-outs, renewals |
| **Payment** | Net 15/30/60, annual vs quarterly, deposit |
| **Support** | Success hours, SLA tier, training |
| **Risk** | Pilot, proof-of-value, milestone gates |
| **Proof** | Case study rights, reference call, logo |

## Trade, never gift

Every concession is **conditional**:

```text
If you [commitment we value], then we can [move we can afford].
```

Examples:

- “If we lock a 24-month term with annual prepaid, I can improve the year-one rate.”
- “If legal accepts our standard DPA, we can start onboarding next Monday.”
- “If we remove custom SSO from phase 1, we can hit your budget without cutting success support.”

## Unbundle before you discount

When price pressure hits, **remove scope** or **phase** before cutting the
same full package’s price. Straight list discounts train buyers to always ask
again and poison renewals.

## Concession pattern

If you must move on price:

- Smaller moves over time (signal approaching floor)
- Never equal large steps that imply infinite room
- Document what you got back each time

## Anchoring

Open with a **credible** commercial structure tied to value — not a weak
“we’re flexible.” Whoever sets the first serious frame shapes the zone.
If they anchor extremely low, do not split the difference blindly; re-anchor
on packages and outcomes.
