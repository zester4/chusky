# Image generation preflight

Use this compact checklist before `CHUCK_GENERATE_IMAGE`:

1. Decide generate, edit, or `reference_variations`; preserve identity/product details when editing.
2. Decide count, aspect ratio, resolution, destination, and whether references are required.
3. Use `CHUCK_LIST_IMAGE_MODELS` when the request needs precise typography, branding, many references, 4K, editing consistency, or a deliberate cost/speed choice; otherwise leave model unset for capability routing.
4. Write an original production brief: subject, action, composition, environment, lighting/color, material/style, typography, and constraints.
5. Read one matching `references/*.md` file only for a specialized style. Learn principles; never copy a reference's identity, brand, wording, or distinctive layout.
6. Generate, inspect the result, and only save or deliver it after the native result confirms success.
