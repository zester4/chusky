# Toolkits for launches

Use the Jev-selected toolkit/account and exact action schema. Separate build,
review, deploy, and publish; production or public writes remain approval- and
policy-gated and require a provider/deployment read-back.

| Need | Toolkit family |
|------|----------------|
| Product ship | `GITHUB_`, `VERCEL_`, `LINEAR_` |
| Email announce | `GMAIL_`, `MAILCHIMP_`, `BEEHIIV_`, `KIT_` |
| Social | `X_`, `LINKEDIN_`, `INSTAGRAM_` |
| Assets | `CANVA_`, `FIGMA_`, native image/video tools |
| Landing / store | `WIX_`, `SHOPIFY_`, `WEBFLOW_` if connected |
| Support macros prep | helpdesk family |

Public posts follow approval policy. Verify live after publish.
