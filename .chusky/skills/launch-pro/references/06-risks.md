# Launch risks

For each risk, identify the evidence, owner, trigger, mitigation, and rollback
decision. Do not convert an unverified warning into a green status or invent a
recovery receipt.

| Risk | Mitigation |
|------|------------|
| Scope creep | Freeze date; parking lot |
| Broken critical path | Dry run; rollback plan |
| Weak messaging | Lock review with owner |
| Support overload | Macros + staffing note |
| Silent failure | Verify live metrics early |
