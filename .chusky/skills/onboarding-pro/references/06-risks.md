# Risks and escalations

## Client risks

| Signal | Response |
|--------|----------|
| No reply 3+ days | Nudge + alternate contact + open loop |
| Scope creep | Re-state agreed success metric; escalate commercial change |
| Access blocked | Parallel path; escalate blocker owner |
| Champion leaves | Rebuild stakeholder map immediately |

## Hiring / employee risks

| Signal | Response |
|--------|----------|
| Offer confusion | Stop; owner clarifies before any message |
| Access lag >1 day | Escalate IT/owner with checklist status |
| Hire silent / stuck | Manager check-in prompt + buddy |
| Role mismatch signs | Document evidence; private escalate to owner |

## Escalation format

1. What is blocked
2. Impact on go-live or ramp
3. Options (A/B)
4. Recommended option
5. Ask / deadline

Escalate early with options. Do not wait for a failed launch to report risk.
