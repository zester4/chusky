# Toolkits for onboarding

| Need | Toolkit family |
|------|----------------|
| Kickoff notes / SOPs | `NOTION_`, `GOOGLEDOCS_`, `GOOGLEDRIVE_` |
| Calendar | `GOOGLECALENDAR_`, `CALENDLY_` |
| CRM stage updates | `HUBSPOT_`, `SALESFORCE_` |
| Access-ish tasks | Track in tasks; provision via real admin tools if connected |
| Hire pipeline | See hiring-pipeline-pro; `WORKABLE_` if connected |
| Client email | `GMAIL_` |

Structure in tasks/attention loops; tools update the systems of record.
