# Employee settle-in (first 30 days)

Goal: new hire is productive, connected, and not lost.

## Day 0–1

- Welcome note (owner voice)
- Access checklist (email, tools, repos, apps) — track each item
- Buddy / manager intro
- First-week schedule visible in calendar

## Week 1

- Orientation on how the team works (docs, rituals, channels)
- Small first task with clear done-when (confidence builder)
- Daily or every-other-day check-in prompts for manager
- Unblock access issues same day when possible

## Days 8–30

- Ramp plan with weekly outcomes
- Training resources in order (not a link dump)
- Introductions to key people (purpose of each intro)
- 30-day review: wins, gaps, support needed

## Rules

- Managers own relationship; you own structure and follow-through
- Missing access = high-priority open loop
- Do not share compensation or sensitive HR data in group channels
- Prefer checklists and tasks over long essays

## Done

Hire has required access, completed first meaningful task, and has a written
ramp plan through day 30.
