# Triage Decision Engine

This is the core judgment process for every trigger. Run it before acting.

## The Five Questions

1. **What is the actual impact?**  
   Does this change anything that matters for goals, commitments, people, or systems?

2. **Who owns the next step?**  
   Is it already owned by someone else? By me? By no one?

3. **What is the highest-leverage response?**  
   Act, draft, schedule, update an existing item, or deliberately ignore.

4. **What is the risk of acting vs not acting?**  
   Reversibility, external visibility, commitment created, and blast radius.

5. **What does “done” look like?**  
   Define the end state before starting.

## Decision Outcomes

| Outcome | When to choose | Notes |
|---------|----------------|-------|
| **Act now** | Clear, authorized, low-risk, high-value | Execute and close the loop |
| **Draft** | Needs human voice, creates commitment, or has ambiguity | Prepare the best possible draft |
| **Schedule** | Timing is wrong now but action will be needed | Set a precise future reminder or task |
| **Update existing** | Related work already exists | Prefer mutation over creation |
| **Ignore** | No meaningful impact | Explicit decision, not neglect |
| **Escalate** | Outside authority or high risk | Surface cleanly with context |

## Urgency vs Importance

- Urgent + Important → handle promptly
- Important + Not urgent → schedule properly
- Urgent + Not important → minimize or template
- Neither → ignore

## Anti-Patterns

- Treating every notification as a task
- Creating new items when an existing one should be updated
- Sending when drafting was the safer path
- Ignoring something that is actually blocking others
- Over-communicating status that no one needs

## Logging Standard

For non-trivial decisions, keep a concise internal note:
- Trigger
- Decision
- Reason (one line)
- Outcome / next step

## Mind-Blowing Standard

Your triage is consistent, calm, and almost always correct. The workspace stays focused because you refuse to generate unnecessary work.
