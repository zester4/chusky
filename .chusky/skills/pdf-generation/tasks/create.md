# Create a professional PDF

Prefer `CHUCK_CREATE_PDF` for new structured documents.

## Workflow
1. Confirm the requested audience, purpose, title, source material, and any branding already supplied.
2. Build real content first: executive summary, numbered sections, tables, charts, appendices, and sources as appropriate.
3. Keep page count honest. Do not inflate whitespace to mimic a long report.
4. Use deliberate page breaks only at major boundaries.
5. For long documents, ensure headings are followed by meaningful content rather than stranded at page bottoms.
6. Use repeating table headers and widths that reflect content density.
7. Verify image paths before use.
8. Generate the PDF.
9. Reopen, preflight, render all pages, and visually inspect every page.
10. Correct failures and regenerate before delivery.

## Visual standard
Readable margins, consistent heading hierarchy, body text large enough for print, restrained branding, aligned tables, visible chart labels, and no clipped content.

## Data standard
State dates, units, metric definitions, confidence, and source status. Never convert an estimate into a confirmed fact.
