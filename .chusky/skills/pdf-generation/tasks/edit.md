# Edit PDFs

Supported classes of edits include merge, split, reorder, rotate, crop, watermark, add page numbers, add metadata, stamp text/images, and remove pages.

Use a PDF library that preserves objects where possible. For major content reflow, regenerate from source instead of attempting fragile object-level edits.

Always write to a new output first, reopen it, confirm page order/count, render changed pages, and visually inspect before replacing an original.
