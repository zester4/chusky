# Fillable forms and annotations

For AcroForm PDFs:
1. inspect field names, types, page mapping, and current values;
2. fill fields using the form layer;
3. preserve appearances or regenerate them when necessary;
4. verify values by reopening the output;
5. render affected pages to confirm visible appearances.

Do not flatten unless the user wants a non-editable result.

For annotations, preserve coordinates, page rotation, author/content fields, and opacity intentionally.
