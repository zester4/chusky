# True PDF redaction

A black rectangle is not redaction.

For sensitive information:
1. locate content;
2. use a redaction feature that removes underlying text/image objects;
3. apply/flatten redactions as appropriate;
4. reopen the PDF;
5. confirm the redacted text is no longer extractable/searchable;
6. inspect rendered pages for residual content;
7. check metadata and attachments if relevant.

Never claim information is removed until extraction verification passes.
