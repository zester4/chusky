# Failed payments and dunning

## Cadence (example; adapt to policy)

1. Day 0 — automatic failure notice + update card link
2. Day 3 — human-ready reminder
3. Day 7 — impact notice (service risk only if true)
4. Day 14+ — escalate per owner policy

## Rules

- Make payment the easy path (link, method)
- Assume good faith first
- Pause dunning if dispute is open and logged
