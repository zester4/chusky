# Styles and normalization

Prefer named styles over direct run formatting.

Check for:
- inconsistent fonts/sizes;
- manual bold headings that should be heading styles;
- inconsistent paragraph spacing;
- mixed list indentation;
- unexpected theme overrides;
- excessive direct formatting.

Normalize conservatively. Do not erase intentional emphasis, code formatting, or brand styling.

Use `scripts/style_lint.py` to surface common inconsistencies.
