# Read and review a DOCX

Use two layers:
- semantic/package inspection for text, styles, comments, fields, tables, metadata;
- visual rendering for layout quality.

For factual/content review, extract document text and structure. For layout review, render first.

Check:
- title and heading hierarchy;
- section transitions;
- tables;
- image placement;
- page numbers;
- headers/footers;
- tracked changes/comments if present;
- broken links/fields;
- metadata if relevant.

Do not infer layout quality from raw XML or text extraction.
