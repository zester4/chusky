# DOCX accessibility

Check:
- semantic headings in logical order;
- meaningful alt text for informative images;
- decorative images marked appropriately where supported;
- table header rows identified;
- tables not used purely for layout when avoidable;
- descriptive hyperlink text;
- readable color contrast if custom colors are used;
- document language when available;
- simple reading order.

Accessibility fixes must not break layout. Re-render after changes.
