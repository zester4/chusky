# Headings, numbering, and TOC

Use Word heading styles so navigation and accessibility work.

For numbering:
- use a consistent multilevel scheme;
- avoid manually typing section numbers when a numbering definition is required;
- keep numbering aligned with heading levels.

For TOC:
- a field-based TOC may require Word/LibreOffice to update;
- if headless rendering does not update fields reliably, make this limitation explicit;
- do not hard-code page numbers unless a static TOC is intentionally requested.

Re-render after TOC/numbering changes.
