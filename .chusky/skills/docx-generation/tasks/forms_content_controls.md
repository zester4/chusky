# Forms and content controls

Word forms can use content controls (SDTs), legacy form fields, or ordinary tables/text.

For SDTs:
- inspect tags/titles;
- preserve binding metadata if present;
- fill only the intended control;
- do not remove protection unintentionally.

If the user only needs a printable form, a structured table with blank fields may be more robust.

See `ooxml/content_controls.md`.
