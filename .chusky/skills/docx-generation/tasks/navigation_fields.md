# Hyperlinks, bookmarks, and fields

Use ordinary hyperlinks when possible. For internal links, use bookmarks plus hyperlink anchors.

Field codes (TOC, REF, PAGE, NUMPAGES, SEQ, etc.) may not update consistently in headless rendering.

When using fields:
1. construct the field correctly;
2. preserve visible cached text if useful;
3. render and inspect;
4. state when a desktop Word refresh may be required.

See `ooxml/hyperlinks_fields.md`.
