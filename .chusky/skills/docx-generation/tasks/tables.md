# Tables and spreadsheet data

For Word tables:
- use explicit column widths when necessary;
- keep text wrapped;
- repeat header rows for multipage tables;
- avoid oversized unbreakable strings;
- align numeric columns consistently;
- keep tables within writable page width;
- use landscape sections only when genuinely needed.

When importing spreadsheets, preserve values and headers, not workbook UI formatting unless the user asks.

Use `scripts/xlsx_to_docx_table.py` and `scripts/docx_table_to_csv.py`.
