# Sections and page layout

Use sections for:
- portrait/landscape changes;
- different margins;
- different headers/footers;
- page-number restarts;
- distinct paper sizes.

Inspect section properties before editing. Avoid accidental section inheritance.

For mixed orientation, verify:
- correct page size;
- margins;
- header/footer linkage;
- table/image fit;
- page numbering continuity.

Always render after section changes.
