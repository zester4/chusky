# Financial models

Financial workbooks require stronger model discipline.

Use separate sections/sheets for:
- assumptions;
- historical data;
- projections;
- calculations;
- outputs/dashboard.

Rules:
- formulas for derived values;
- assumptions in dedicated cells;
- units and periods labeled;
- currency clearly stated;
- source URLs/comments for researched inputs;
- scenario inputs separated from formulas;
- checks for balance/roll-forward logic when relevant;
- no hidden magic numbers.

Clearly distinguish actuals, estimates, forecasts, and run-rate/annualized metrics.
