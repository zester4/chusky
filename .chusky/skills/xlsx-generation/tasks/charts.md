# Charts

A chart must answer a question, not merely decorate a sheet.

Before creating:
- verify source values are numeric/date-compatible;
- limit categories to a readable set;
- choose a chart type that matches the relationship.

After creating:
- add a meaningful title;
- set axis number formats;
- place the chart away from data;
- avoid overlapping cells needed for work;
- check legend placement;
- render and inspect labels.

Prefer simple line, column/bar, or scatter charts unless a more complex chart is clearly justified.
