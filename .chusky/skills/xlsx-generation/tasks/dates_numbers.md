# Dates, numbers, currency, percentages

Store real numeric/date values and apply formats.

Examples:
- date: `yyyy-mm-dd`
- month: `mmm yyyy`
- percentage: `0.0%`
- integer: `#,##0`
- decimal: `#,##0.00`
- currency: use the requested/local currency format

Do not store dates as ambiguous text if users need sorting, formulas, or charts.
