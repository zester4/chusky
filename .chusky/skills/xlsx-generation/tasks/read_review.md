# Read, review, and analyze a workbook

Start by listing sheets, then inspect only the relevant ranges.

For model review, check:
- inputs vs formulas vs outputs;
- hidden assumptions;
- hard-coded values inside formula regions;
- inconsistent formulas down a column;
- broken references;
- totals that exclude newly added rows;
- units and time periods;
- duplicate or ambiguous labels;
- charts linked to the wrong ranges.

For visual review, render the relevant sheet/range and inspect clipping, widths, frozen panes, chart placement, and hierarchy.
