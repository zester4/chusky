# Render and visually verify

Render important sheets/ranges before delivery when formatting or charts matter.

Check:
- clipped text;
- hidden headers;
- excessive white space;
- columns too narrow/wide;
- row heights;
- wrapping;
- frozen panes;
- conditional formatting;
- chart position and labels;
- dashboard balance;
- visible formula errors.

Rendering is a visual QA layer; formula inspection is still required.
