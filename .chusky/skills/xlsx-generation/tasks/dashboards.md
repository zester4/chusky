# Dashboards and KPI areas

Use a dashboard when the user needs quick status or trend interpretation.

A good dashboard can include:
- 3–6 KPI cards;
- one or two trend charts;
- a small status table;
- clear period/filter labels.

Keep source/detail data on a separate sheet when practical. The dashboard should summarize, not duplicate the whole workbook.

Use formulas that point to source ranges rather than manually painting KPI values.
