# Formatting and layout

Formatting should communicate hierarchy and meaning.

Use:
- styled headers;
- correct number formats;
- bounded column widths;
- wrap text for long descriptions;
- alignment appropriate to data type;
- freeze panes for long datasets;
- light borders/fills;
- whitespace between logical sections.

Avoid:
- merged cells inside data tables;
- excessive colors;
- giant row heights or widths from uncontrolled autofit;
- centered long-form text;
- text-formatted numbers that should be numeric.
