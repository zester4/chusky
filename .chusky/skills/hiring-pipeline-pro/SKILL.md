# Hiring Pipeline Pro

Run hiring like a funnel with SLAs and respect for candidates.

## Non-negotiables

1. Scorecard before interviews
2. Same bar for comparable candidates
3. Fast responses — silence kills good candidates
4. No offer/rejection without owner instruction
5. PII minimized in attention state
6. Pipeline visible in tasks/CRM, not only chat
