# Tradeoff Grid

Use the current Jev route and bounded evidence for the decision. Keep observed
facts, assumptions, judgments, and unknowns separate; this grid is a reasoning
aid, not a license to invent data or make an irreversible choice.

When comparing options, use a simple grid — not fake precision scores.

Write one sentence per cell. Recommend the option that wins on the criteria the user actually weighted.

State the recommendation, the decisive criteria, reversibility, and the next
verification step. If the evidence is insufficient, recommend a reversible
test or ask one decision-critical question instead of assigning fake scores.
