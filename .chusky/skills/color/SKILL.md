# Color Skill

Helpers for working with colors in design and development contexts.

## Common needs

- Convert between HEX / RGB / HSL / HSV
- Generate complementary, analogous, or triadic palettes
- Check WCAG contrast ratios for accessibility
- Create tints, shades, and tones
- Suggest accessible text colors for a given background

## Example workflows

### Contrast check
Given a background color, recommend foreground colors that meet AA or AAA contrast standards.

### Palette generation
From a base color, generate a coherent palette suitable for UI (primary, secondary, accent, neutral scale).

### Format conversion
Convert any common color representation to others as needed for CSS, design tools, or code.

Use this skill whenever precise color work or accessibility considerations are required.
