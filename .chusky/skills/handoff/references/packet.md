# Handoff packet schema

Every handoff should include:

1. **Objective** — one sentence
2. **Done when** — testable criteria
3. **Constraints** — tools, approvals, deadlines, disclosure limits
4. **Context** — only facts required to continue
5. **Evidence so far** — what was verified
6. **Blockers** — if any
7. **Next action** — single concrete step
8. **Ids** — task id, handoff id, meeting id, etc. when they exist

Omit passwords and raw secrets. Point to vault/session instead.
