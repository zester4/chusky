# Video generation preflight

Use this compact checklist before `CHUCK_GENERATE_VIDEO`:

1. Decide the format, aspect ratio, duration, resolution, audio, destination, and whether a reference or first/last frame is needed.
2. For demanding work, call `CHUCK_LIST_VIDEO_MODELS` first and choose by motion, consistency, audio, dialogue, speed, and cost; otherwise use capability-aware routing.
3. Write a shot-aware brief: subject continuity, action, camera movement, framing, lighting, environment, transition, sound, and negative constraints.
4. For multi-shot work, define numbered shots and keep character, wardrobe, location, lighting, and camera logic consistent.
5. Read one matching video reference only when the style is specialized. Learn production principles; never copy protected identities, brands, wording, or distinctive scenes.
6. Generation is asynchronous. Wait for verified completion before claiming the clip exists or using its workspace path.
