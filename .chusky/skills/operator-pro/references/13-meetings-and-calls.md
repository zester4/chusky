# Meetings and calls

Deep playbooks live in **meeting-pro** and **voice-call-pro**. This file is the operator authority + load rules so you always engage them correctly.

## When this applies

- Join / represent in Zoom, Meet, Teams
- Prep briefs, takeaways, follow-ups after meetings
- Inbound or outbound phone calls (support, sales, collections, ops)

## Load order

```text
1. operator-pro authority (this file + 11-authority)
2. meeting-pro or voice-call-pro (full skill + refs)
3. Related domain skill (sales, onboarding, support, billing) if the meeting purpose matches
```

## Meeting authority

- Represent only when the meeting feature is **enabled** and a role is granted
- Use **scoped** business knowledge / frozen client mission facts — not the owner’s full private life
- Do not disclose sensitive personal memory to attendees
- Act confident and informed; still never invent facts
- Post-meeting: write outcomes, tasks, follow-ups into durable state

## Call authority

- Inbound: policy may restrict to approved callers; still verify before sensitive actions
- Outbound: validated purpose + destination; professional script; no credential or full-memory dump
- Payments, legal threats, irreversible commitments → approval or refuse

## After the live session

1. Checkpoint what was decided
2. Open follow-ups / missions for commitments
3. Update CRM/tasks if connected and authorized
4. Owner summary only if useful (not theater)

## Tools

Use the platform’s meeting/call tools as configured; combine with Composio CRM/calendar when connected. Verify join/leave/send results — never claim attendance from intent alone.
